# Neon Coast Heat

Neon Coast Heat は、three.js で描くオープンワールドの犯罪ゲームです。舞台はシード付きの手続き生成で生まれる海岸都市ソラノ。9×9ブロックの街区が広がり、南側は海に面しています。デスクトップブラウザで遊ぶゲームで、操作はキーボードとマウスです。ネットワーク通信は使わず、静的なファイルだけで動きます。

## 街を歩く、車を奪う、逃げ切る

主人公のリコは、徒歩でも車でも街を自由に動き回れます。道路には交通の流れがあり、歩行者が行き交い、駐車中の車が並んでいます。気に入った車があれば乗り込んでそのまま走り去ることもできますが、それは犯罪です。街で起こした騒ぎはヒートとして蓄積され、星の数で手配度が表れます。星が増えるほど追ってくるパトカーも増え、最大で5つ星、1つ星あたり2台のパトカーが追跡してきます。警察の目を逃れて身を隠している間は、ヒートは少しずつ下がっていきます。追い詰められれば逮捕、体力が尽きれば病院送りです。

## ミッションと稼ぎ

ストーリーミッションは5件。街のフィクサーから依頼を受け、銀行や港、桟橋などを舞台に仕事をこなしていきます。合間にはサイドジョブで現金を稼ぐこともできます。街のあちこちには隠された金の隠し場所が12か所あり、見つけるたびに報酬が入ります。12か所すべて見つければ特別なボーナスもあります。手持ちの現金は、逮捕されると一部を没収され、倒れれば病院代がかかります。

## 画面と音

画面には円形のミニマップ付きHUDが表示され、自分の位置や目的地、警察の動きがひと目でわかります。効果音は手続き型で、その場で合成して鳴らしています。BGMや効果音はミュートもできます。進行状況はセーブ機能で保存でき、次に遊ぶときは続きから再開できます。

## 操作

- 移動と運転：W・A・S・Dキーまたは矢印キー。走るときはShiftキーを押しながら。
- 車に乗る・降りる、車を盗む：Eキー。
- 射撃：スペースキーまたはマウスクリック。
- パンチ：Fキー。
- クラクション：Hキー。
- ミュート：Mキー。
- ポーズ：PキーまたはEscキー。
- メニューの決定：Enterキー。

## ビルドと遊び方

出力先ディレクトリを MAKEFUN_OUTPUT_DIR で指定して main.ts を node で実行すると、静的ファイル一式がその出力先に生成されます。serve.ts を使うと生成物をローカルで配信でき、ブラウザを開いてそのまますぐに遊べます。スクリーンショットは、URLに ?shot=start、?shot=drive、?shot=chase、?shot=mission のいずれかを付けたステージングで撮影します。
